Screen Video on Local Network

How to enable display streaming across Wi-Fi / LAN

Browsers (Chrome, Edge, Safari) protect screen capture by restricting getDisplayMedia to Secure Contexts (localhost or https://). To stream screen video across LAN devices, choose any option below:

1
Option A: Run SwiftView with HTTPS (Recommended)

Restart server with HTTPS to enable automatic TLS on LAN:

npm run start:https
Then open https://<your-local-ip>:4173 on your phone/laptop and accept the local self-signed certificate.
2
Option B: Chrome / Edge Developer Flag (10 seconds)

Tell Chrome to treat this LAN address as secure for screen sharing:

  1. Open chrome://flags/#unsafely-treat-insecure-origin-as-secure
  2. Paste this origin: http://localhost:4173
  3. Select Enabled and click Relaunch.
3
Option C: Zero-Install Dev Shell & Remote Admin

You can connect right now! Remote terminal, system telemetry, commands, and AI copilot work directly over HTTP without any setup.
